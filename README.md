# Конкурсьер

Учёт активности конкурса в одном сообществе ВКонтакте. Администратор запускает конкурс, ВК присылает события на сайт, баллы складываются в рейтинг. Участники на сайт не регистрируются.

Баллы по умолчанию:

- вступление в сообщество: 5
- лайк записи на стене сообщества: 1
- комментарий к записи на стене: 2
- репост записи стены сообщества: 2

Числа меняются в админке. Повтор одного действия не даёт баллы второй раз. Снятие лайка, удаление комментария и выход из сообщества снимают свои баллы.

Репост записи стены сообщества считается один раз на человека за конкурс. Удаление репоста баллы не снимает.

## Что система не считает

Не считаются лайки комментариев, фото, видео и товаров. Не считаются комментарии к фото, видео, товарам и в обсуждениях. Не считается заявка на вступление, пока её не одобрят. Не считается активность до запуска: ВК не отдаёт дату старого лайка и дату старой подписки, поэтому прошлый месяц подтянуть нельзя.

Правка комментария баллы не меняет. Комментарий от имени самого сообщества не считается.

## Что нужно на хостинге

- PHP 8.0 или новее, расширения `pdo_mysql`, `curl`, `json`, `mbstring`
- MySQL или MariaDB
- HTTPS
- Apache, чтобы сработал `.htaccess`

Cron не нужен. Отдельный сервер и постоянный процесс не нужны.

## Установка на REG.RU

1. В панели хостинга создайте базу MySQL и пользователя с полными правами на эту базу.
2. Загрузите все файлы проекта в каталог сайта (`public_html` или `www/домен`).
3. Скопируйте `config.example.php` в `config.php`. Впишите хост, имя базы, пользователя и пароль. Часовой пояс по умолчанию `Europe/Moscow`.
4. Откройте `https://ваш-домен/install.php`, задайте пароль администратора.
5. Удалите `install.php` с хостинга.
6. Войдите в админку и откройте «Подключение».

Если пароль потерян: в phpMyAdmin удалите строку `admin_password_hash` из таблицы `settings`, удалите файл `storage/install.lock` и снова откройте `install.php`.

## Подключение сообщества

1. В сообществе: Управление, Дополнительно, Работа с API. Создайте ключ доступа и вставьте его в админку.
2. Туда же вставьте ID сообщества или адрес страницы, строку подтверждения со вкладки Callback API и секретный ключ.
3. Нажмите «Сохранить и проверить». Сайт вызовет `groups.getById` и покажет имя сообщества. Пока ВК не ответил, настройки не сохраняются.
4. На вкладке Callback API добавьте сервер. Адрес показан в админке, обычно `https://ваш-домен/callback.php`. Версия API: **5.199**. Секретный ключ должен совпадать с ключом в админке.
5. Сначала сохраните строку подтверждения в админке, потом нажмите «Подтвердить» в ВК. Код из метода API другой, он не подойдёт.
6. Включите события: вступление, выход, новый комментарий на стене, удаление комментария, восстановление комментария, новая отметка «Мне нравится», снятие отметки, репост записи.

После этого на странице «Подключение» в журнале появляются входящие события.

## Конкурс

На странице «Конкурс» укажите название и срок, затем нажмите «Запустить». Одновременно идёт только один конкурс. В минуту окончания начисление останавливается само, кнопку «Завершить» можно нажать раньше.

Рейтинг: место, имя, фамилия, ссылка на ВК, баллы. Одинаковые баллы делят место, следующее место пропускается. CSV открывается в Excel: UTF-8 и разделитель «точка с запятой».

Кнопка «Обновить имена из ВК» нужна, если ВК не успел отдать имя в момент события. За один раз обновляется до 300 человек.

Уже начисленные баллы при смене стоимости действия не пересчитываются. Новые события берут новую стоимость. Ноль выключает действие.

### Ссылка принятия акции

Если при запуске включить «Учитывать баллы только после перехода по ссылке», лайки, комментарии и вступление попадут в рейтинг только после того, как человек откроет ссылку мини-приложения из записи.

1. На [dev.vk.com](https://dev.vk.com/) создайте мини-приложение.
2. В админке на странице «Подключение» укажите ID приложения и защищённый ключ. Адрес приложения: `https://ваш-домен/join.php`.
3. При запуске конкурса включите галочку. На странице конкурса появится ссылка вида `https://vk.com/app{id}_-{группа}` — её вставьте в запись.
4. Человек открывает ссылку внутри ВК и принимает акцию. Действия до перехода сохраняются и засчитываются в этот момент; снятие лайка или удаление комментария до принятия отменяет их.
